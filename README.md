# Google Keyword Research

个人海外需求发现工具。

## 项目目标

本项目不是面向公众销售的关键词查询 SaaS，而是一个供项目所有者个人使用的研究工具：通过 Google Ads API / Keyword Planner 获取关键词搜索需求数据，再结合趋势、商业意图、竞争度等信息，帮助发现值得进一步验证和开发的海外产品机会。

## 核心原则

1. **先发现需求，再开发产品**：工具本身不是最终商业产品。
2. **数据优先**：第一阶段优先使用 Google 官方 API，不通过抓取 Google 搜索结果获得搜索量。
3. **验证优先于开发**：发现高潜关键词后，再研究用户、竞品、付费意愿和 MVP。
4. **个人效率优先**：第一版保持简单，不做账号体系、支付、复杂权限等非必要功能。
5. **AI 是分析层，不是数据源**：AI 用于解释和评分，不伪造搜索量数据。
