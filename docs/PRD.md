# 产品需求文档（PRD）

## 1. 产品定位

本项目是个人使用的 **AI 海外需求发现与产品机会分析工具**。它不是 Google Keyword Planner 的克隆，也不是广告投放工具。

核心目标：帮助项目所有者在开发海外 AI / SaaS / Web 工具之前判断：有没有真实需求、需求是否增长、商业意图是否明确、竞争是否可进入、是否适合个人开发。

核心闭环：

> 种子想法/关键词 → 关键词扩展 → 搜索需求估算 → 趋势 → SERP/竞品 → 社区痛点 → 商业意图 → AI 分析 → Opportunity Score → MVP 建议

## 2. 产品目标

1. 把“发现海外需求 → 验证需求 → 找到产品机会”变成可重复的个人研究流程。
2. 一个种子想法可以自动扩展成关键词集合，并发现高潜需求。
3. 基于多源数据生成产品机会报告，包括用户、痛点、竞品、商业模式、MVP 和风险。

## 3. 非目标

- 不做公开注册 SaaS。
- 不做收费系统。
- 不做广告投放。
- 不依赖 Google Ads / Keyword Planner。
- 不声称提供 Google 官方精确搜索量。
- 不通过爬虫绕过平台访问控制。
- 不保证某个产品一定成功。
- 第一版不接入大量昂贵数据源。

## 4. MVP 功能

### 4.1 研究项目

- 项目名称
- 种子关键词
- 国家/地区
- 语言
- 备注

### 4.2 关键词扩展

支持语义、功能、人群、场景、痛点、地区和商业意图扩展。AI 生成关键词必须标记为 AI generated，不能冒充真实搜索数据。

### 4.3 搜索需求估算

通过可替换的 Search Volume Provider 获取：

- estimated monthly searches
- monthly history（Provider 支持时）
- CPC（Provider 支持时）
- competition（Provider 支持时）
- country
- language
- source
- retrieved_at

界面必须明确显示“估算值”和数据来源。

### 4.4 趋势分析

分析长期/短期趋势、增长速度、稳定性、季节性及相关上升查询（Provider 支持时）。

### 4.5 SERP / 搜索结果分析

提取排名、URL、Domain、标题、页面类型、竞品类型、大型品牌/独立产品等信息，用于判断竞争强度和弱竞争 SERP 机会。

### 4.6 社区痛点

优先分析 Reddit 等公开社区，提取用户、问题、抱怨、现有解决方案、产品不满和付费线索。

### 4.7 竞品分析

记录产品、URL、功能、目标用户、免费方案、付费方案、价格、定位和用户评价/抱怨。

### 4.8 Opportunity Score

- Search Demand：20%
- Trend：15%
- Commercial Intent：20%
- Competition：15%
- Pain Point：15%
- Monetization：10%
- MVP Difficulty：5%

详细规则见 `docs/OPPORTUNITY_SCORING.md`。

### 4.9 AI 产品机会报告

输出需求解释、用户画像、搜索意图、商业意图、痛点、竞品、切入点、MVP、定价、风险、开发难度、Opportunity Score 和最终建议。

## 5. 核心用户流程

### 验证一个想法

1. 输入种子关键词。
2. 选择国家和语言。
3. AI 扩展关键词。
4. 获取搜索需求估算。
5. 查看趋势。
6. 筛选高潜关键词。
7. 分析 SERP 和竞品。
8. 分析 Reddit/社区痛点。
9. 生成 AI 产品机会报告。
10. 保存研究结论。

### 批量寻找机会

1. 输入多个种子关键词。
2. 批量扩展。
3. 批量获取需求估算。
4. 按机会评分筛选。
5. 对 Top 机会进行深度分析。
6. 输出产品机会排行榜。

## 6. 数据原则

- 不把第三方估算数据称为 Google 官方数据。
- 外部数据保存 source、retrieved_at、country、language 和必要原始上下文。
- 数据源通过 Provider 接口隔离。
- API 失败必须明确提示，禁止用假数据冒充真实结果。
- AI 推断必须与原始数据分离并明确标记。
- 重复请求必须缓存。

## 7. MVP 验收标准

输入 `invoice` 等种子关键词后，系统能够完成：

> 关键词扩展 → 需求估算 → 趋势 → SERP → 社区痛点 → 竞品 → Opportunity Score → 产品机会报告

并能够保存研究项目和结果。第一版优先验证研究闭环，不以页面复杂度或代码量作为成功标准。
